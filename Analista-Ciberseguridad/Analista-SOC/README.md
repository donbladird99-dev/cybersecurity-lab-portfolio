Este repositorio documenta mi proceso de formación práctica en ciberseguridad mediante un laboratorio basado en entornos Windows y Active Directory. Incluye prácticas orientadas a la administración y seguridad de sistemas, análisis de eventos, investigación de incidentes, uso de PowerShell y fundamentos de análisis SOC.

El proyecto busca demostrar de forma práctica habilidades en detección, análisis, correlación y documentación de eventos de seguridad, siguiendo un enfoque basado en evidencias. Las prácticas incluyen escenarios como autenticaciones fallidas, cuentas deshabilitadas, bloqueo de usuarios, análisis de registros de seguridad y construcción de líneas de tiempo para determinar la secuencia de un incidente.

El objetivo es mantener un portafolio técnico que evidencie la evolución de mis conocimientos y mi capacidad para aplicar conceptos de ciberseguridad en escenarios prácticos de laboratorio.
